# JEE Main PYQ Analysis & Practice Portal — Project State & Roadmap

## 1. Project Goal & Target Architecture (What We Want to Build)

The objective is to build a completely offline-capable, locally stored, interactive JEE Main Previous Year Questions (PYQ) analysis and practice system based on 90 MathonGo PDF question papers (2021 to 2025) across Physics, Chemistry, and Mathematics.

The finished project is designed to deliver:
1. Master Priority & Strategy Dashboard:
   - 3-Bucket Chapter System:
     * Bucket 1: High Priority / Master First (~48-52 Physics/Chemistry, ~28-32 Mathematics target).
     * Bucket 2: Expansion Booster Block (~+65 marks additional).
     * Bucket 3: Formula-Only / Restricted Zone.
     * Bucket 0: Official syllabus chapters not in reference cheat sheet (flagged as High Frequency).
     * Bucket -1: Conflict chapters where historical 5-year PYQ frequency diverges significantly from strategy assumptions.
   - Master PCM weightage rankings and exportable high-resolution printable PDFs.
2. Comprehensive Chapter & Topic Taxonomy:
   - Full coverage across all 73 official JEE Main syllabus chapters with question counts, 5-year trends, and shift-by-shift distributions.
3. Semantic Problem-Solving Clusters:
   - Categorizing repetitive PYQs into 3-5 core archetypes per chapter (e.g., Logic Gates & Truth Tables, Zener Diode as Voltage Regulator, P-N Junction Diodes) instead of treating every question as an isolated problem.
4. Interactive Test-Series UI (Matching modern apps like Marks / ExamGOAL):
   - Modern dark mode theme (`#0d0d11` / `#18181c` cards with `#27272e` borders).
   - Metadata pills: Question Number, Year & Shift (e.g., `JEE Main 2024 (Online) 8th April Evening Shift`), Marking scheme (`MCQ +4 -1` or `Numerical +4 0`).
   - Cleanly rendered question text with embedded math and diagrams.
   - Four distinct, selectable option cards [A], [B], [C], [D] (or numerical input box for integer questions).
   - Single action button: `Check answer` that instantly reveals the verified official key without page reload, turning the user selection green if correct or red if wrong, with the correct option highlighted in green.
5. GitHub Repository:
   - Clean version control synced to `https://github.com/Hozaifah47/JEE-` on branch `main`.

## 3. Current Limitations & Root Cause Analysis

1. Missing Question Diagrams / Figures:
   - Questions referring to figures (e.g., "as shown in the figure", circuit diagrams, ray diagrams, graphs, pulleys) currently lack their diagrams.
   - Cause: Text extraction tools only extract character streams. Embedded visual images in the PDFs require raster image extraction and bounding-box image cropping to be saved and linked in HTML.
2. Flattened Truth Tables & Matrices:
   - Truth tables (like logic gate input/output tables) and matrix grids are drawn in PDFs with vector lines and coordinate text, not ASCII tables.
   - Cause: Word-level extraction flattens 2D columns into a single string (e.g., `A B Y 0 0 1 0 1 1...`) rather than an HTML `<table>`.
3. Incomplete Options on Complex Layouts:
   - Some multi-column questions in earlier PDF formats had floating option blocks that were not fully captured during regex splitting.
