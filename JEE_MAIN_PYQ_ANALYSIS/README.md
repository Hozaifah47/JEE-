# JEE Main PYQ Analysis System

A complete offline system for systematic analysis of JEE Main Previous Year Question Papers (2021–2025) from MathonGo.

---

## 🎯 Purpose

This system ingests 90 JEE Main PYQ PDFs, extracts all questions, classifies them by chapter and topic, clusters similar questions by problem-solving approach, analyses frequency trends, and generates a full HTML dashboard — all locally, with no paid APIs.

## 🚀 How to Use

### Prerequisites

```bash
pip install pymupdf          # PDF text extraction (PyMuPDF)
# No other dependencies required (stdlib only)
```

### Step-by-Step Pipeline

Run from the project root:

```bash
cd /home/hozaifah/HozzCode/JEE/JEE_MAIN_PYQ_ANALYSIS
```

#### Step 1 — Ingest (Register PDFs)
```bash
python 07_SCRIPTS/ingest.py
```
Scans `01_RAW_PYQS/YYYY/` and registers all PDFs in `source_inventory.csv` and `master_manifest.json`.

Options:
```bash
python 07_SCRIPTS/ingest.py --dry-run     # Preview only, no writes
python 07_SCRIPTS/ingest.py --year 2024   # Only 2024 papers
```

#### Step 2 — Extract Questions
```bash
python 07_SCRIPTS/extract_questions.py
```
Extracts all questions from registered PDFs using PyMuPDF + regex heuristics.

Options:
```bash
python 07_SCRIPTS/extract_questions.py --file-id JEE-2024-0129-S1
python 07_SCRIPTS/extract_questions.py --year 2024
python 07_SCRIPTS/extract_questions.py --force   # Re-extract already-done papers
```

#### Step 3 — Classify Questions
```bash
python 07_SCRIPTS/classify_questions.py
```
Matches each question to a chapter using keyword rules from `chapter_taxonomy.json`.

Options:
```bash
python 07_SCRIPTS/classify_questions.py --subject Physics
python 07_SCRIPTS/classify_questions.py --reclassify   # Redo all
```

#### Step 4 — Cluster Questions
```bash
python 07_SCRIPTS/cluster_questions.py
```
Groups questions within each chapter by problem-solving approach. Assigns `cluster_id` to each question.

Options:
```bash
python 07_SCRIPTS/cluster_questions.py --subject Mathematics
python 07_SCRIPTS/cluster_questions.py --chapter Electrostatics
```

#### Step 5 — Analyse Trends
```bash
python 07_SCRIPTS/analyse_trends.py
```
Computes year-wise, shift-wise, and cluster-wise frequency stats. Outputs JSON files to `04_MASTER_REPORTS/`.

#### Step 6 — Generate HTML Dashboard
```bash
python 07_SCRIPTS/generate_html.py
```
Generates the full HTML dashboard in `04_MASTER_REPORTS/`. Open `04_MASTER_REPORTS/index.html` in a browser.

Options:
```bash
python 07_SCRIPTS/generate_html.py --subject Physics
python 07_SCRIPTS/generate_html.py --output-dir /custom/path
```

#### Validate (Any Time)
```bash
python 07_SCRIPTS/validate_database.py
```
Checks ID uniqueness, chapter assignments, cluster integrity, and question counts per paper.
Outputs `00_ADMIN/quality_control_report.html` and `00_ADMIN/coverage_report.html`.

## 🗒 Notes

- **Never move** original PDFs from `/home/hozaifah/HozzCode/JEE/` — the copies in `01_RAW_PYQS/YYYY/` are what the system reads.
- MathonGo PDFs use image-rendered math in many questions; PyMuPDF extracts only text layers. Questions with images will have partial text — these are flagged with `review_required: true`.
- `classify_questions.py` uses keyword rules (no AI). For better accuracy, manually review flagged questions or enhance `chapter_taxonomy.json` keyword lists.
- All scripts are **idempotent** — safe to re-run; they skip already-processed items unless `--force` or `--reclassify` is passed.
