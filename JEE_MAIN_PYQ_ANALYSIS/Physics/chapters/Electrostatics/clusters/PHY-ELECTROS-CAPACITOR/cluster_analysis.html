📐 General Problem-Solving Approach

C = ε₀A/d (parallel plate). Series: 1/C = Σ(1/Cᵢ). Parallel: C = ΣCᵢ. Energy U = ½CV² = Q²/2C. With dielectric: C' = KC.

📋 Required Formulae

  • U = ½CV² = Q²/2C
  • C_dielectric = Kε₀A/d
