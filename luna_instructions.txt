# Instructions for Codex GPT‑5.6 (Luna)

## Purpose
This file serves as a living task list for Luna. Luna should read the file at start‑up, execute the listed actions, and then update the file with status, results, or new tasks as the project evolves.

## How Luna should interact
1. **Periodic Check** – Every time Luna runs (or on a scheduled interval, e.g., every 5 minutes), it must read this file to see if new instructions have been added.
2. **Execution** – For each unfinished task, Luna should:
   - Perform the required action (e.g., run a script, modify a file, generate assets).
   - Append a line starting with `✅` when the task succeeds, or `⚠️` with an error description if it fails.
   - If the task creates new files or alters existing ones, Luna should note the file paths.
3. **Self‑Update** – After completing a task, Luna can add follow‑up items (e.g., “Run truth‑table formatter”) by inserting a new bullet under the **Pending Tasks** section.
4. **Idempotency** – Tasks should be safe to re‑run. Luna may skip any line that already has a `✅` prefix.

## File Structure
```
# Instructions for Codex GPT‑5.6 (Luna)

- [ ] <description of task>
- [ ] <another task>

## Completed Tasks
- ✅ <task description> – <timestamp>

```
